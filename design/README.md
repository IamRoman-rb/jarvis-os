# Diseño visual — "Obsidian Kinetic HUD"

Mockups generados con Google Stitch. Son **referencia estética** para el tema de XFCE, íconos,
wallpaper, la ventana de confirmación y cualquier UI propia de JARVIS.

| Carpeta | Contenido |
|---|---|
| `stitch/obsidian_kinetic_hud/DESIGN.md` | Design system: paleta, tipografías (Space Grotesk + JetBrains Mono), elevación, formas, componentes |
| `stitch/debian_jarvis_workstation_desktop/` | Escritorio completo (HTML + captura) |
| `stitch/debian_jarvis_gestor_de_archivos_stark_files/` | Gestor de archivos |
| `stitch/icon_*` | Íconos SVG: núcleo de JARVIS, terminal, archivos, configuración |

Notas:

- Los mockups mencionan Wayland; el objetivo técnico es **X11** (ver `CLAUDE.md`). Se toma solo la estética.
- Los textos de ficción (Stark, Mark-85, etc.) son decorativos; no se usan en la UI real.
- Implementar el tema (GTK/xfwm4, íconos, wallpaper) corresponde a la fase 4 (imagen del sistema).
