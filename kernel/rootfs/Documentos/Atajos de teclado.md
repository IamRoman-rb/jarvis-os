# Atajos de JARVIS-OS

| Tecla | Qué hace |
|---|---|
| Tab | Cambiar entre JARVIS y Archivos |
| Espacio | JARVIS dice una frase (en el HUD) |
| ↑ ↓ | Moverse por la lista |
| Enter | Abrir la carpeta |
| Retroceso | Subir una carpeta |
| F7 | Nueva carpeta |
| F2 | Renombrar |
| Supr | Mandar a la Papelera (en la Papelera: borrar definitivo) |
| Esc | Cancelar / volver a JARVIS |
