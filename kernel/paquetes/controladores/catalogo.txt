# Catálogo de controladores de JARVIS-OS (ADR 0023): qué hardware tiene driver, y qué firmware
# necesita. Lo usa `controladores` (y Configuración → Hardware). Viene adentro del sistema y se
# actualiza con `sudo controladores actualizar` (lo sirve el puente desde kernel/paquetes/).
#
#   pci VVVV:DDDD | driver | nombre
#   pci clase CC:SS:PP | driver | nombre         (PP = * para cualquiera)
#   usb clase CC | driver | nombre
#   firmware driver | ruta en el disco | URL (linux-firmware) | SHA-256
#
# Los drivers son parte del kernel (no se cargan aparte): un driver nuevo llega con una versión
# nueva de JARVIS-OS. Lo que sí se baja aparte es el firmware, que es el mismo para todos los
# sistemas operativos.
